# 风险检测框架 — 规则库、评分模型与严重程度标准

> 本文件是AI合同风控官的核心检测引擎，定义了所有风险规则、扣分标准和分级逻辑。

## 一、风险分类体系

## 二、详细风险规则库

### D1: 条款缺失 (Clause Deficiency)

#### 规则 D1.01 - 缺少违约责任条款

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D1-001 |
| **风险名称** | 缺少违约责任条款 |
| **严重程度** | 🔴 CRITICAL |
| **默认扣分** | -20 |
| **适用场景** | 所有合同类型 |
| **检测逻辑** | 全文扫描"违约""违反""责任""赔偿""违约金"等关键词 → 如均未发现或仅提及但无具体内容 |
| **问题描述** | 合同未约定任何违约责任条款。一旦一方违约，守约方将难以追究对方的法律责任，也无法预先估算违约成本以威慑潜在违约行为。 |
| **法律依据** | 《民法典》第577条：当事人一方不履行合同义务或者履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者赔偿损失等违约责任。虽法律规定了兜底责任，但缺乏具体约定将增加举证难度和不确定性。 |
| **建议修改** | 补充完整的违约责任章节，至少包括：(1)违约情形列举；(2)违约金计算方式或具体金额；(3)赔偿范围（直接损失+间接损失）；(4)违约金上限。 |
| **建议文本模板** | > "任何一方违反本合同约定，应向守约方支付合同总额__%的违约金。违约金不足以弥补守约方损失的，违约方还应赔偿差额部分（包括但不限于直接损失、预期利益损失、维权费用等）。双方另有约定的从其约定。" |

---

#### 规则 D1.02 - 缺少保密条款

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D1-002 |
| **风险名称** | 缺少保密义务条款 |
| **严重程度** | 🟠 HIGH |
| **默认扣分** | -12 |
| **适用场景** | 所有涉及商业信息的合同（排除简单的一次性现货买卖） |
| **检测逻辑** | 扫描"保密""机密""不得披露""非公开"等词 → 未找到或仅有口头提及 |
| **问题描述** | 合同缺少明确的保密义务条款。在合作过程中，双方必然会接触到对方的商业秘密（如客户名单、定价策略、技术方案等），若无保密约束，信息泄露后将难以追责。 |
| **法律依据** | 《反不正当竞争法》第9条：经营者不得实施侵犯商业秘密的行为。但主张商业秘密保护需证明"采取了相应保密措施"。 |
| **建议修改** | 增加保密条款，明确：(1)保密信息定义；(2)保密义务；(3)例外情形（公知信息/独立开发/司法要求）；(4)保密期限（建议不少于合作结束后2-3年）；(5)违反后果。 |

---

#### 规则 D1.03 - 缺少知识产权归属条款

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D1-003 |
| **风险名称** | 缺少知识产权归属条款 |
| **严重程度** | 🟠 HIGH |
| **默认扣分** | -12 |
| **适用场景** | 服务合同、技术开发合同、合作/联营协议 |
| **检测逻辑** | 涉及创作/开发的合同中扫描"知识产权""著作权""专利""商标""归属""所有权"等词 → 未找到 |
| **问题描述** | 合同涉及智力成果创造但未约定知识产权归属。根据《民法典》规定，委托开发的知识产权默认归开发者所有（除非另有约定），这意味着委托方可能花了钱却拿不到IP。 |
| **法律依据** | 《民法典》第859-860条（委托开发合同）、第861条（合作开发合同）。职务发明相关：《专利法》第6条。 |
| **建议修改** | 明确约定合作过程中产生的以下IP的归属：(1)背景知识产权（Background IP）— 归各自所有；(2)前景知识产权（Foreground IP）— 建议"归委托方所有"或"共有"；(3)衍生作品的权利行使方式。 |

---

#### 规则 D1.04 - 缺少争议解决条款

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D1-004 |
| **风险名称** | 缺少争议解决方式与管辖条款 |
| **严重程度** | 🟠 HIGH |
| **默认扣分** | -10 |
| **适用场景** | 所有合同类型 |
| **检测逻辑** | 扫描"争议""纠纷""仲裁""诉讼""管辖""法院"等词 → 未找到 |
| **问题描述** | 未约定争议解决方式。发生纠纷时，需按法定管辖原则确定管辖法院（被告住所地/合同履行地），可能导致异地诉讼的高昂成本。 |
| **法律依据** | 《民事诉讼法》第34条（协议管辖）、《仲裁法》第4-5条（或裁或审）。 |
| **建议修改** | 建议约定：(1)首选仲裁（一裁终局、保密性强、国际执行力强）— 推荐贸仲CIETAC/北仲BAC/新加坡SIAC/香港HKIAC；(2)次选诉讼— 约定对自己方便的管辖法院。注意避免既选仲裁又选诉讼（会导致仲裁条款无效）。 |

---

#### 规则 D1.05 - 缺少合同变更与解除条款

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D1-005 |
| **风险名称** | 缺少合同变更/解除条款 |
| **严重程度** | 🟡 MEDIUM |
| **默认扣分** | -6 |
| **适用场景** | 所有长期合同（期限>3个月） |
| **检测逻辑** | 扫描"变更""修改""解除""终止""提前结束"等词 → 未找到 |
| **问题描述** | 合同未约定变更和解除的程序与条件。市场环境变化时无法灵活调整，想退出时缺乏清晰的退出路径。 |
| **法律依据** | 《民法典》第543条（协商一致变更）、第562条（约定解除）、第563条（法定解除）。 |
| **建议修改** | 增加：(1)书面变更程序（须经双方签字盖章）；(2)约定解除权的触发条件（分不同严重程度设置）；(3)法定解除权的重申；(4)解除的通知方式和生效时间。 |

#### 规则 D1.06 - 缺少不可抗力条款

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D1-006 |
| **风险名称** | 缺少不可抗力条款 |
| **严重程度** | 🔵 LOW |
| **默认扣分** | -3 |
| **适用场景** | 所有合同类型 |
| **检测逻辑** | 扫描"不可抗力""force majeure""天灾""疫情"等词 → 未找到 |
| **问题描述** | 未约定不可抗力的范围和处理方式。虽然《民法典》第590条有法定不可抗力规定，但具体哪些事件构成不可抗力、通知时限、后果分担等细节需要明确约定。 |
| **法律依据** | 《民法典》第180条（不可抗力定义）、第590条（免责效果）、第533条（情势变更）。 |
| **建议修改** | 列举不可抗力事件类型（自然灾害、战争、政府行为、流行病等），并约定：(1)受影响方的及时通知义务（如48小时内）；(2)证明材料提供义务；(3)免责范围（部分还是全部免除）；(4)后续处理（延期/减量/解除）。 |

### D2: 责任不对等 (Imbalanced Liability)

#### 规则 D2.01 - 单方违约责任不对等

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D2-001 |
| **风险名称** | 双方违约责任明显不对等 |
| **严重程度** | 🔴 CRITICAL |
| **默认扣分** | -15 |
| **适用场景** | 所有合同类型 |
| **检测逻辑** | 提取双方各自的违约金比例/计算方式 → 比较 → 若一方违约金是另一方的2倍以上或一方无上限另一方有限额 |
| **问题描述** | 合同中双方的违约责任存在显著不对称。例如：甲方违约只需支付5%违约金，而乙方违约需支付30%并赔偿全部损失。这种不对等条款可能被认定为显失公平的格式条款而无效。 |
| **法律依据** | 《民法典》第497条（格式条款无效情形）、第6条（公平原则）。 |
| **建议修改** | 将双方违约责任调整为对等或接近对等水平。若因客观原因确实需要对等（如货物价值差异），应在合同中说明合理的差异化理由。 |

---

#### 规则 D2.02 - 单方解除权过大

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D2-002 |
| **风险名称** | 一方享有无因解除权或极低成本的解除权 |
| **严重程度** | 🔴 CRITICAL |
| **默认扣分** | -18 |
| **适用场景** | 服务合同、劳动合同、经销/代理协议 |
| **检测逻辑** | 搜索"有权解除""可无条件""无需...通知""不承担...责任" + 仅出现在一方权利中 |
| **问题描述** | 合同赋予一方（通常是强势方）无理由或低成本解除合同的权利，而另一方解除则需要满足严苛条件或支付高额赔偿。这是典型的霸王条款。 |
| **法律依据** | 《民法典》第563条（法定解除权）、第566条（解除后果）。 |
| **建议修改** | (1)删除无因解除权，改为基于正当理由的解除；（2）若保留无因解除权，则必须给予合理的通知期（≥30天）和经济补偿（覆盖已投入成本）；(3)确保双方解除权基本对等。 |

---

#### 规则 D2.03 - 赔偿上限缺失或单边

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D2-003 |
| **风险名称** | 赔偿责任无上限或仅限制一方 |
| **严重程度** | 🟠 HIGH |
| **默认扣分** | -12 |
| **适用场景** | 服务合同、技术开发合同、合作协议 |
| **检测逻辑** | 检查是否有"最高不超过""不超过""上限""cap"等限额表述 → 若完全无上限 或仅一方有限额 |
| **问题描述** | 合同一方的赔偿责任没有上限（理论上可能是天文数字），而另一方的赔偿却设有封顶。这将导致无上限的一方面临不可预测的巨额风险敞口。 |
| **法律依据** | 《民法典》第584条（损失赔偿=违约造成的损失，包括合同履行后可以获得的利益，但不得超过违约一方订立合同时预见到或者应当预见到的损失）。 |
| **建议修改** | 为双方分别设定合理的赔偿责任上限，通常为：(1)过去12个月已付费用的一定倍数（如1-3倍）；或(2)合同总额的一定比例（如50%-100%）。注意：故意违约/侵权行为通常不适用责任上限。 |

---

#### 规则 D2.04 - 通知义务不对等

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D2-004 |
| **风险名称** | 双方通知义务的时间/方式要求不一致 |
| **严重程度** | 🟡 MEDIUM |
| **默认扣分** | -5 |
| **适用场景** | 所有合同类型 |
| **检测逻辑** | 分别提取各方"通知"相关条款 → 比较 → 时间要求差异>3倍 或 方式要求不同 |
| **问题描述** | 一方的通知期限远短于另一方（如一方需提前30天，另一方仅需3天），或一方可用邮件通知另一方必须快递公证，实质上造成信息不对称。 |
| **法律依据** | 《民法典》第137条（意思表示的送达生效）。 |
| **建议修改** | 统一双方的通知方式和时限要求。推荐：重要事项书面通知（含电子邮件），普通事项可采用便捷方式，通知期限保持一致。 |

---

#### 规则 D2.05 - 知识产权归属不合理

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D2-005 |
| **风险名称** | 工作成果知识产权全归一方所有 |
| **严重程度** | 🟠 HIGH |
| **默认扣分** | -10 |
| **适用场景** | 技术开发、服务、合作类合同 |
| **检测逻辑** | 检测IP条款中"归甲方所有""乙方放弃""永久独占"等表述 + 无任何反向授权/许可 |
| **问题描述** | 合同约定合作过程中产生的所有知识产权（无论是否使用了乙方的背景技术）均归甲方所有。这对付出创造性劳动的乙方极为不公平，也可能打击积极性导致服务质量下降。 |
| **法律依据** | 《民法典》第859条（委托开发合同中无约定时IP归研发人）、《著作权法》第18条（职务作品）。 |
| **建议修改** | 采用分层IP归属方案：(1)乙方已有的背景IP归乙方，授予甲方免费永久使用许可；(2)专门为甲方定制开发的前景IP归甲方；(3)通用性的改进和创新成果双方共有或归乙方（甲方获得使用许可）。 |

### D3: 合规风险 (Regulatory Compliance)

#### 规则 D3.01 - 违反强制性法律规定

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D3-001 |
| **风险名称** | 条款违反法律强制性/禁止性规定 |
| **严重程度** | 🔴 CRITICAL |
| **默认扣分** | -25 |
| **适用场景** | 所有合同类型 |
| **检测逻辑** | 对照各法域强制性法规数据库 → 发现冲突条款 |
| **常见违规类型** | · 劳动合同试用期超过法定上限<br>· 竞业限制无经济补偿<br>· 民间借贷利率超出LPR4倍<br>· 免责条款免除人身伤害责任<br>· 格式条款排除主要权利<br>· 房屋租赁合同租期超20年<br>· 加盟合同特许人未备案<br>· 排除消费者依法投诉举报权利 |
| **问题描述** | 合同中含有违反法律强制性规定的条款，该条款自始无效。更严重的是，此类违规可能导致行政机关介入调查甚至行政处罚。 |
| **法律依据** | 《民法典》第153条（违反法律、行政法规的强制性规定的民事法律行为无效）。 |
| **建议修改** | 立即删除或修改该条款使其符合法律要求。必要时咨询执业律师确认具体整改方案。 |

---

#### 规则 D3.02 - 税务合规风险

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D3-002 |
| **风险名称** | 价税分离不清或税务责任约定不明 |
| **严重程度** | 🟠 HIGH |
| **默认扣分** | -10 |
| **适用场景** | 采购/销售/服务/技术开发合同 |
| **检测逻辑** | 检查金额条款是否区分含税价/不含税价、税率、税种及承担方 |
| **问题描述** | 合同价款未明确是否含税、税率多少、谁负责申报缴纳。这可能导致：(1)实际到手金额低于预期；(2)重复征税；(3)税务稽查风险（尤其是发票问题）。 |
| **法律依据** | 《增值税暂行条例》《企业所得税法》《税收征收管理法》。 |
| **建议修改** | 明确约定："本合同总价为人民币___元（含增值税，税率___%）。甲方应在每笔款项支付前收到乙方开具的合规增值税专用发票。" |

---

#### 规则 D3.03 - 劳动法合规风险

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D3-003 |
| **风险名称** | 劳动合同条款违反劳动法律法规 |
| **严重程度** | 🔴 CRITICAL |

| **常见违规** | · 试用期工资低于正式工资80%<br>· 要求劳动者支付培训违约金但未提供专业技术培训<br>· 竞业限制超过2年或未约定经济补偿<br>· 强制放弃社保缴纳<br>· "末位淘汰"式辞退<br>· 约定"工伤自负"<br>· 试用期单独签订（非合同期限内）<br>· 违法延长工作时间无补休/加班费 |

| 属性 | 说明 |
|:-----|:-----|

| **严重程度** | 🟠 HIGH |
| **默认扣分** | -10 |
| **适用场景** | 租赁合同、服务订阅、SaaS协议、会员协议 |

| **规则ID** | R-D5-001 |
| **风险名称** | 合同模板占位符未被实际内容替换 |
| **严重程度** | 🟠 HIGH |
| **默认扣分** | -10 |
| **适用场景** | 使用模板生成的合同 |

| **严重程度** | 🟠 HIGH |

### D6: 跨境合规 (Cross-border Compliance)

#### 规则 D6.01 - 管辖权/法律选择不当

| 属性 | 说明 |
|:-----|:-----|
| **规则ID** | R-D6-001 |
| **风险名称** | 争议解决管辖地或适用法律选择对己方极度不利 |
| **严重程度** | 🟠 HIGH |
| **默认扣分** | -12 |
| **适用场景** | 涉外合同 |
| **检测逻辑** | 分析当事人所在地 vs 约定的管辖法院/仲裁机构/适用法律 → 判断便利性和中立性 |
| **问题描述** | 合同选择了对一方极其不方便的管辖地点或适用法律（如在纽约诉讼但双方都是中国企业在华经营），将大幅增加争议解决的成本和不确定性。 |
| **法律依据** | 《民事诉讼法》第34条（协议管辖）、《涉外民事关系法律适用法》。 |
| **建议修改** | 优选：(1)国际知名中立仲裁机构（新加坡SIAC、香港HKIAC、ICC巴黎）；(2)如选诉讼，选择对双方都相对便利的中立地（如被告住所地或合同履行地）。避免选择对方"主场"的法院。 |

| **建议修改** | (1)明确收付币种及汇兑安排；(2)通过正规银行渠道办理外汇收支；(3)大额交易提前了解外汇局的审批/备案要求。 |

## 三、风险评估矩阵

### 严重程度定义

| 等级 | 符号 | 分值范围 | 定义 | 行动要求 |
|:-----|:-----|:---------|:-----|:---------|
| **CRITICAL** | 🔴 | -15 ~ -25 | 致命风险：可能导致合同无效、重大财产损失、行政处罚或刑事责任 | **必须修改后才可签署** |
| **HIGH** | 🟠 | -8 ~ -15 | 高风险：严重损害己方权益，高概率引发纠纷 | **强烈建议修改** |
| **MEDIUM** | 🟡 | -3 ~ -8 | 中等风险：权益不平衡或有改进空间 | **建议修改** |
| **LOW** | 🔵 | -1 ~ -3 | 低风险：小瑕疵、建议优化或行业惯例偏差 | **可选优化** |
| **INFO** | ⚪ | 0 | 信息级：无风险但值得关注的事项 | **仅供参考** |
