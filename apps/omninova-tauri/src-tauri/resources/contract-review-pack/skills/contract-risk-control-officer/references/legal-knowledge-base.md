### 中国法域审查速查要点

```markdown
⚡ 高频踩坑点 TOP 10：

1. 民间借贷利率不得超过LPR的4倍（约13.8%/年，动态变化）
2. 劳动合同必须书面形式；试用期最长6个月（≥3年合同）；试用期工资≥正式工资80%
3. 竞业限制最长2年，必须按月支付经济补偿（不低于离职前30%）
4. 格式条款中"免除己方责任、加重对方责任、排除主要权利"的无效
5. 房屋租赁期限不得超过20年（超过部分无效）
6. 定金不得超过主合同标的额的20%
7. 加盟合同：特许人必须在商务部门备案；加盟人有"单方解除权"（特许条例12条）
8. 违约金约定过高时可请求法院适当减少（一般不超过损失的30%）
9. 建设工程合同：承包人享有建设工程价款优先受偿权（18个月内）
10. 电子合同：可靠的电子签名与手写签名/盖章具有同等法律效力
```

## 🇺🇸 美国 (United States)

### 法律体系特点
- **联邦制**：联邦法 + 50个州法并行，合同争议主要由州法管辖
- **Common Law（普通法）**：判例法为主，UCC（统一商法典）统一商事规则
- **At-will Employment**：大多数州实行雇佣自由（雇主可无理由解雇）
- **Punitive Damages**：惩罚性赔偿在某些案件中可能极高

### 核心法律框架

| 类别 | 法律/法规 | 核心内容 |
|:-----|:---------|:---------|
| **合同通则** | Common Law Contract Principles | 要约-承诺-约因-履约能力-合法性 |
| **商事合同** | UCC Article 2（货物买卖） | 明示担保+默示担保（ merchantability + fitness for particular purpose ） |
| **雇佣** | At-will Employment (多数州) | 可随时解雇；但受反歧视法/集体合同/公共政策例外限制 |
| | Non-competition Agreements | 各州效力差异极大（加州基本无效，NY/TX较宽松） |
| **消费者保护** | FTC Act Section 5 | 禁止"不公平或欺诈性行为" |
| | State UCC/Consumer Laws | 各州消费者保护法（如加州Song-Beverly Act） |
| **知识产权** | 17 U.S.C. (Copyright) / 35 U.S.C. (Patent) | Work-for-hire doctrine（雇员作品归雇主） |
| **数据隐私** | CCPA/CPRA（加州） | 美国最严隐私法；类似GDPR |
| | State Privacy Laws | 弗吉尼亚/科罗拉多等多州跟进 |
| **反垄断** | Sherman Act / Clayton Act / FTC Act | 卡特尔、滥用支配地位、合并审查 |
| **证券** | Securities Act of 1933 / Exchange Act of 1934 | 投资合同中的披露义务 |
| **出口管制** | EAR (Export Administration Regulations) / ITAR | 受控物项/技术/软件出口需许可证 |
| **制裁** | OFAC Sanctions Program (SDN List等) | 与制裁对象交易将被严厉处罚 |

### 美国合同审查速查要点

```markdown
⚡ 高频踩坑点 TOP 10：

1. 州法差异巨大——必须确认适用的州法律（Choice of Law）
2. UCC vs Common Law——货物买卖走UCC，服务合同走Common Law
3. Choice of Forum——联邦法院vs州法院差异大（陪审团/程序/时间）
5. Punitive Damages——某些州（如FL/NM/TX）惩罚性赔偿极高
6. Non-compete——加州/ND/MT/OK基本禁止，NY新规限制（年收入<25万美元不可执行）
7. Indemnification（赔偿/补偿）条款在美国非常普遍且范围很广
8. Merger Clause（完整协议条款）防止外部证据引入
9. Attorney's Fees（律师费）——美国规则（各自承担）vs 英美规则（败诉方承担）因州而异
10. Force Majeure——COVID-19后此条款变得非常重要
```

## 🇬🇧 英国 (United Kingdom)

### 法律体系特点
- **English Common Law**（英国普通法）：判例法为核心，合同自由原则强
- **Brexit后变化**：不再受欧盟法院管辖，但保留了大部分欧盟法转化为国内法
- **Implied Terms（默示条款）**：即使合同没写，法院也会默示一些条款（如Service Fit for Purpose）
- **Remedies（救济）**：以损害赔偿为主，特定履行(Specific Performance)较少

### 核心法律框架

| 类别 | 法律/法规 | 核心内容 |
|:-----|:---------|:---------|
| **合同法** | Common Law Contract Principles (case law) | 要约-承诺-约因-建立合同关系的意图-履约能力 |
| | Contracts (Rights of Third Parties) Act 1999 | 第三方可依合同起诉 |
| **货物销售** | Sale of Goods Act 1979 (as amended) | 默示条款： satisfactory quality, fit for purpose, correspondence with description |
| **服务供给** | Supply of Services Act 1982 | 以合理技能和谨慎提供服务 |
| **消费者保护** | Consumer Rights Act 2015 | 30天退货权；6个月内质量问题推定出卖时就存在 |
| | Consumer Protection from Unfair Trading Regulations 2008 | 禁止不公平商业行为 |
| **数据隐私** | UK GDPR + Data Protection Act 2018 | Brexit后独立于EU GDPR但高度一致 |
| **雇佣** | Employment Rights Act 1996 | 不当解雇/裁员/产假/工资保障 |
| **知识产权** | Copyright, Designs and Patents Act 1988 | 职务作品(Copyright: s11); 专利(Patents Act 2004) |
| **竞争法** | Competition Act 1998 / Enterprise Act 2002 | 卡特尔刑事化；市场滥用 |
| **仲裁** | Arbitration Act 1996 | 英国是国际仲裁热门地（LCIA） |

### 英国合同审查速查要点

```markdown
⚡ 高频踩坑点 TOP 8：

1. Consideration（约因）——普通法合同成立的必要条件（赠与合同除外）
2. Implied Terms——即使合同没写的，法律也会默示插入（货物/服务合同尤其多）
3. Exclusion clauses（免责条款）——Unfair Contract Terms Act 1977 和 Consumer Rights Act 2015 限制
4. Breach of contract分为 condition（可终止合同）和 warranty（仅可索赔）——分类很重要！
5. English law下"reasonable endeavors"比"best efforts"义务轻得多
6. Post-Brexit——注意是否适用英国法或保留EU law元素
7. GDPR vs UK GDPR——数据条款需确认适用哪个版本
8. LCIA仲裁——伦敦是最受欢迎的国际仲裁地之一
```

## 🇸🇬 新加坡 (Singapore)

### 法律体系特点
- **英美法系**（继承英国普通法传统）
- **Contract Act of Singapore**（新加坡合同法）— 成文法+判例法结合
- **国际仲裁中心**（SIAC）— 全球前三的仲裁机构所在地
- **亲商环境**：法治健全、营商环境全球领先
- **多元文化**：英/中/马来语均为官方语言

### 核心法律框架

| 类别 | 法律/法规 | 核心内容 |
|:-----|:---------|:---------|
| **合同法** | Contracts Act (Cap 32B, Rev Ed 2020) | 新加坡合同法核心成文法 |
| | Common Law | 补充成文法的判例法规则 |
| **货物买卖** | Sale of Goods Act (Cap 393, Rev Ed 1999) | 类似英国SGA的默示条款 |
| **数据隐私** | Personal Data Protection Act (PDPA, 2012修订) | 类似GDPR但相对宽松；跨境传输需满足要求 |
| **雇佣** | Employment Act (Cap 91, Rev Ed 2024) | 月收入≤$5,000的员工受保护范围扩大 |
| | Employment Claims Act 2016 | 劳动争议通过就业索赔法庭 |
| **知识产权** | Registered Patents Rules / Trade Marks Act / Copyright Act | IP保护体系完善 |
| **竞争法** | Competition Act (Cap 86B, Rev Ed 2024) | 卡特尔/滥用支配地位/合并控制 |
| **仲裁** | International Arbitration Act (Cap 143A) | SIAC（新加坡国际仲裁中心）规则 |
| **贪污防治** | Prevention of Corruption Act (PCA) | 反贿赂极严（包括境外贿赂） |

### 新加坡合同审查速查要点

```markdown
⚡ 高频踩坑点 TOP 6：

1. PCA（反贪法）非常严格——即使是海外行贿也受新加坡管辖
2. PDPA——个人数据保护不如GDPR严但仍需重视，罚款高达100万新元
3. Employment Act 2024改革——更多员工纳入保护（薪资上限提高）
4. SIAC仲裁——如果选新加坡做仲裁地，SIAC是首选
5. 电子交易法——电子签名和电子合同具有完全法律效力
6. 多语言环境——合同语言选择（中英文双语需明确效力优先级）
```

## 🇩🇪 德国 (Germany)

### 法律体系特点
- **Civil Law（大陆法系）**：以《德国民法典》(BGB)为核心的成文法体系
- **严谨细致**：BGB条文极其详尽（共2385条），合同规则非常具体
- **Good Faith（诚信原则）**：§242 BGB（善意/诚实信用）贯穿整个合同法
- **消费者保护强**：欧盟指令转化为国内法 + 德国本土更严格的保护

### 核心法律框架

| 类别 | 法律/法规 | 核心内容 |
|:-----|:---------|:---------|
| **民法典** | Bürgerliches Gesetzbuch (BGB) | 第1-3编（合同相关）：总则、债法、物权法等 |
| **消费者保护** | BGB §305c-310（格式合同条款规制） | AGB法（一般条款法）——格式条款内容审查极其严格 |
| | Verbraucherschutzgesetz (VerbrSchG) | 消费者保护综合立法 |
| **雇佣** | BGB §611 ff.（雇佣合同） | 解雇保护（Kündigungsschutz）/ 最低工资 |
| | Bundesurlaubsgesetz (BUrlG) | 带薪休假（最少24天/年） |
| **数据隐私** | BDSG（联邦数据保护法）+ GDPR | GDPR全面适用 |
| **知识产权** | Urheberrechtsgesetz (UrhG) / Patentgesetz / MarkenG | IP保护体系 |
| **竞争法** | Gesetz gegen Wettbewerbsbeschränkungen (GWB) | 反垄断 + 反不正当竞争（UWG） |
| **租赁** | BGB §§535-580a（Mietrecht） | 租客保护极强（驱逐难/租金管控/ pets allowed默认） |

### 德国合同审查速查要点

```markdown
⚡ 高频踩坑点 TOP 8：

1. AGB（一般条款/格式条款）——德国法院对格式条款审查极严，大量条款会被认定为无效
2. §305c BGB —— 有疑问时，作不利于使用格式条款一方的解释
3. §309 BGB —— 黑名单条款（绝对无效）vs §308（灰名单/可推翻）
4. Mietrecht（租赁法）——租客保护在欧洲最强之一，房东很难涨租金/驱逐
5. Kündigungsschutz（解雇保护）——雇佣10人以上公司的解雇需社会正当性
6. Nachfristsetzung（催告程序）——违约后通常需要先给一个补救期（Nachfrist）才能解除
7. Widerrufsrecht（撤回权）——远程销售/B2C合同中消费者的14天撤回权
8. Datenschutz —— GDPR在德国执行尤为严格，各州数据保护局活跃
```

## 🇯🇵 日本 (Japan)

### 法律体系特点
- **大陆法系**（继受德国法，后融入美国法元素）
- **民法典（Minpō）**：合同法核心，1898年施行，2017年大修（2020年生效）
| **印章文化（印鉴/Hanko）** | 正式合同通常需要实印+印鉴证明（Inkan Shōmeisho）
| **善意的通知（善意的通知権）** | 日本独特的制度
| **取消权（取消権）** | 因欺诈/胁迫等原因可撤销的意思表示

### 核心法律框架

| 类别 | 法律/法规 | 核心内容 |
|:-----|:---------|:---------|
| **民法（民法典）** | 民法（明治29年法律第89号，2017年改正） | 第三编「契約」为合同法核心；2017年改正现代化了合同规则 |
| **劳动基准法** | 労働基準法 | 劳动条件最低标准；36協定（加班协定） |
| | 労働契約法 | 劳动合同的特殊规则；无固定期限劳动合同转换 |
| **个人信息保护** | 個人情報保護法（APPI） | 2022年修订加强（类似GDPR）；罚款上限1亿日元 |
| **独占禁止法** | 私的独占の禁止及び公正取引の確保に関する法律 | 反垄断法（公正取引委员会JFTC执法） |
| **消费者保护** | 消費者契約法 | 不当条款撤销权；消費者基本法 |
| **IP** | 特許法 / 意匠法 / 商標法 / 著作権法 | 职务发明（特許法35条）——发明者有"相当的利益金"受领权 |
| **公司法** | 会社法（会社法） | 株式会社/合同公司等组织形式 |

### 日本合同审查速查要点

```markdown
⚡ 高频踩坑点 TOP 8：

1. 印鑑（Hanko）——实印+印鉴证明是正式合同的标准做法，电子合同正在兴起但尚未普及
2. 2017年民法改正——合同法部分大幅现代化（如：债务不履行归责结构的改变）
3. 消費者契約法——消费者可撤销的不当条款范围广泛
4. 労働契約法——雇佣合同满10年自动转为无固定期限（有例外）
5. 职务发明——特許法35条：雇员有权获得"相当的报酬"，企业不能通过合同完全排除
6. APPI（個人情報保護法）——2022年修订后更接近GDPR，跨境传输需满足条件
7. 取引法（下請法）——分包/外包中发包方不得滥用优势地位（ parentNode/子会社間も適用）
8. 契約書の言語——日文合同为标准，英文合同在日本法院也认可
```

## 🇦🇺 澳大利亚 (Australia)

### 法律体系特点
- **Australian Common Law**（继承英国普通法）
- **Australian Consumer Law (ACL)** — 联邦+州统一的消费者保护法，**极强**
- **Unfair Contract Terms** — 对标准格式合同（B2B年营业额<$100万/$250万）的不公平条款可被判定无效
- **Competition and Consumer Act 2010** — 反垄断+消费者保护的统一立法
- **State-based Property Law** — 房地产法由各州自行规定

### 核心法律框架

| 类别 | 法律/法规 | 核心内容 |
|:-----|:---------|:---------|
| **合同通则** | Australian Common Law | 英美法系合同原则 |
| **消费者保护** | Australian Consumer Law (Schedule 2 to CCA) | 消费者保障极强：自动法定担保（fit for purpose等）不可排除 |
| | Unfair Contract Terms provisions (ACL Div 2 Part 2-3) | B2B标准合同（小企业）中的不公平条款无效 |
| **竞争法** | Competition and Consumer Act 2010 (CCA) | 反垄断（ACCC执法）+消费者保护一体化 |
| **数据隐私** | Privacy Act 1988 (as amended) | APPs（澳大利亚隐私原则）；Notifiable Data Breaches scheme |
| **雇佣** | Fair Work Act 2009 | National Employment Standards (NES)；现代裁决制度 |
| **IP** | Copyright Act 1968 / Patents Act 1990 / Trademarks Act 1995 | IP保护体系 |
| **仲裁** | International Arbitration Act 1974 (CIETAC Model Law) | ACICA（澳大利亚国际仲裁中心） |

### 澳大利亚合同审查速查要点

```markdown
⚡ 高频踩坑点 TOP 6：

1. ACL Consumer Guarantees——消费者法定担保不可通过合同排除（即使合同写了"不提供任何担保"）
2. Unfair Contract Terms——年营业额<$100万（或<$250万用于某些条款）的小企业的标准格式合同中的不公平条款无效
3. ACCC执法积极——反垄断+消费者保护由同一个强力机构执行
4. Privacy Act——APPs（13条隐私原则）；数据泄露需通知OAIC和受影响个人
5. State property laws——房地产相关合同需关注所在州的特殊规定（NSW/VIC/QLD各有不同）
6. Franchise Code of Conduct——加盟合同受《Franchising Code》严格规制（强制披露、冷却期等）
```

## 🇨🇦 加拿大 (Canada)

### 法律体系特点
- **双法域**：魁北克省(Quebec)适用**Civil Code**（大陆法系），其余各省适用**Common Law**
- **联邦-省分权**：某些领域联邦立法（破产/版权/刑法），某些领域省级（财产/合同/侵权）
- **Consumer Protection** — 各省消费者保护法各异（魁克 strongest）
| **PIPEDA** — 联邦层面私人信息安全保护法（类似GDPR但较弱）

### 核心法律框架

| 类别 | 法律/法规 | 适用范围 |
|:-----|:---------|:---------|
| **合同通则** | Common Law Provinces (ON/BC/AB etc.) | 英美法系合同原则 |
| | Quebec Civil Code (CCQ) | 大陆法系合同原则（第七编"Obligations"） |
| **消费者保护** | Consumer Protection Act (各省政府立法) | Ontario CPA / Quebec LPBC / BC CPA等 |
| **隐私** | PIPEDA (Personal Information Protection and Electronic Documents Act) | 联邦层面的私营部门隐私法 |
| | Quebec's Private Sector Privacy Act (Bill 64/Law 25) | 魁北克的隐私法（比PIPEDA更严格，类似GDPR） |
| **雇佣** | Canada Labour Code (联邦) + Provincial Employment Standards | 联邦+省双层劳动法 |
| **竞争法** | Competition Act (R.S.C., 1985, c. C-34) | Bureau of Competition (CB)执法 |
| **IP** | Copyright Act / Patent Act / Trademarks Act | 联邦立法全国统一 |
| **仲裁** | 各省Arbitration Acts | 各省仲裁法（多采UNCITRAL Model Law） |

### 加拿大合同审查速查要点

```markdown
⚡ 高频踩坑点 TOP 6：

1. Civil Law vs Common Law——魁克省用CCQ（大陆法），其他省份用Common Law，两者合同规则差异很大
2. Consumer Protection——各省消费者法差异大（魁北克LPBC最强），需确认适用省份的法律
3. PIPEDA vs Quebec Law 25——隐私保护在魁北克更严（同意要求/数据本地化/ breach notification）
4. Language rights——魁北克的法语要求（法语在商业活动中享有特权地位）
5. Employment standards——联邦+省双重管辖，需确认适用于哪一层级
6. Competition Bureau——反垄断执法（卡特尔刑事化；加拿大是全球最早将卡特尔犯罪化的国家之一）
```

## 🇪🇺 欧盟 (European Union)

### 法律体系特点
- **Supranational（超国家）**：欧盟法优先于成员国国内法（ supremacy principle ）
- **Direct Effect（直接效力）**：某些欧盟法规可直接在成员国法院援引
- **GDPR（通用数据保护条例）** — 全球影响力最大的数据隐私法
- **Digital Services Act (DSA) / Digital Markets Act (DMA)** — 平台经济新规
- **Member States仍保留** 合同法的核心领域（各国合同法未完全统一化）

### 核心法律框架

| 类别 | 法律/法规 | 核心内容 |
|:-----|:---------|:---------|
| **数据隐私** | GDPR (Regulation 2016/679) | **全球最严隐私法**；处理合法性基础；数据主体权利；跨境传输（SCCs/Adequacy）；DPO任命；DPIA； breach 72h通知；最高罚款2000万€或全球营收4% |
| | Digital Governance Act (DGA) | 数据共享框架 |
| **消费者保护** | Consumer Rights Directive (2011/83/EU) | 14天远程销售撤回权；信息告知义务；数字内容供应 |
| | Unfair Contract Terms Directive (93/13/EEC) | B2C不公平条款黑名单/灰名单 |
| | Unfair Commercial Practices Directive (2005/29/EC) | 禁止误导性行为和 omission |
| **数字市场** | Digital Services Act (DSA) | 平台义务（非法内容/透明度/广告/推荐算法） |
| | Digital Markets Act (DMA) | "Gatekeeper"平台的义务（互操作性/数据便携性/公平访问） |
| **AI监管** | AI Act (Regulation 2024/1689) | AI系统按风险分级监管（Prohibited/High/Limited/Minimal Risk） |
| **竞争法** | TFEU Articles 101-102 | 卡特尔/滥用支配地位（欧盟委员会DG COMP执法） |
| **反制裁** | EU Sanctions Regulations | 与美国/UK协调但有时独立的制裁体系 |
| **产品责任** | Product Liability Directive (85/374/EEC, revised 2024) | 缺陷产品无过错责任 |
| **合同法统一化（有限）** | CESL（Common European Sales Law）— proposed but not adopted | 合同法统一进程缓慢，目前仍以成员国法为主 |

### 欧盟合同审查速查要点

```markdown
⚡ 高频踩坑点 TOP 8：

1. GDPR——绝对的核心焦点。几乎所有涉及个人数据的合同都必须包含数据处理条款（DPA）
2. GDPR跨境传输——向非 adequacy 国家传输数据需要SCCs（标准合同条款）+ TIA（传输影响评估）
3. DSA/DMA——如果是平台/在线 intermediary，新增大量合规义务
4. AI Act——如果合同涉及AI系统供应/使用，需评估AI风险等级
5. Member State Law choice——合同法仍以成员国法为准，需确认 Choice of Law
6. Rome I Regulation（EC No 593/2008）——合同法律适用的统一规则
7. Brussels I Regulation（Recast, EU No 1215/2012）——管辖权的统一规则
8. Euro as currency——欧元区国家的合同注意汇率/通胀条款
```
