# 批量处理工作流指南

> 本文件定义AI合同风控官在批量审查模式下的操作规范、效率优化和汇总报告标准。

---

## 一、批量模式概述

### 能力指标

| 指标 | 标准 |
|:-----|:-----|
| **单批上限** | 100份合同/次 |
| **单份解析速度** | ≤10秒（20页以内PDF） |
| **批量总耗时** | ≤8分钟（100份） |
| **并发处理能力** | 最高10份并行扫描 |
| **输出形式** | 每份独立报告 + 汇总对比报告 |

### 触发条件

当用户一次上传 **≥2份** 合同时，自动进入批量模式：

```
用户输入: "帮我审一下这10份采购合同"
    ↓ 识别到多文件 → 自动切换批量模式
    ↓
并行执行:
  ├─ 合同1 → 解析→提取→扫描→评分→报告
  ├─ 合同2 → 解析→提取→扫描→评分→报告
  ├─ ...
  └─ 合同N → 解析→提取→扫描→评分→报告
    ↓ 全部完成后
生成汇总报告（聚类+排行+趋势+行动建议）
```

## 二、批量处理工作流

### Phase 1: 预检与预处理 (Pre-check)

```
输入: N份合同文件
输出: 通过预检的合格文件列表 + 异常报告

步骤:
1. 文件格式验证
   ├── 支持格式: PDF / Word(.docx) / 图片(PNG/JPG) / 纯文本(TXT)
   ├── 不支持的格式 → 记录异常,跳过
   └── 图片/扫描件 → 启动OCR队列

2. 文件完整性检查
   ├── 空白文件/损坏文件 → 标记为"无法读取"
   ├── 加密文件/密码保护 → 提示用户提供密码
   └── 文件大小异常(<1KB或>100MB) → 标记预警

3. 去重检测
   ├── 文件名相似度 > 90% → 可能是重复
   ├── 文本内容哈希相同 → 确定重复
   └── 版本关系识别(v1/v2/v3) → 可选启动版本比对模式

4. 分类归组
   ├── 按合同类型分组(采购/销售/劳动/...)
   ├── 按供应商/客户归集(如有当事人信息)
   ├── 按时间排序(如可从文件名/元数据获取)
   └── 标注优先级(高风险类型优先)

输出示例:
✅ 通过预检: 95份
⚠️ OCR待处理: 3份(扫描件)
❌ 无法读取: 2份(加密)
🔄 重复文件: 1份(已去重保留最新版)
```

### Phase 2: 并行审查引擎 (Parallel Review)

```
架构设计:

┌─────────────────────────────────────┐
│         任务调度器 (Scheduler)        │
│  · 维护任务队列                      │
│  · 分配工作线程(最多10个并行)         │
│  · 监控进度与超时                    │
│  · 处理失败重试                     │
└──────────┬──────────────────────────┘
           │ 分发
     ┌─────┼─────┬─────┐
     ▼     ▼     ▼     ▼
  ┌────┐┌────┐┌────┐┌────┐
  │W-01││W-02││W-03││... │  ← 工作线程
  │    ││    ││    ││    │
  └──┬─┘└──┬─┘└──┬─┘└──┬─┘
     ▼     ▼     ▼     ▼
  [结果1][结果2][结果3][...]

每个工作线程的处理流程(与单份合同完全一致):
  Step 1: 文本预处理(OCR/编码清洗)
  Step 2: 类型识别(12种合同分类)
  Step 3: 关键条款提取(50+字段)
  Step 4: 六维风险扫描(38条规则)
  Step 5: 综合评分(100分制)
  Step 6: 生成独立报告
```

### Phase 3: 结果聚合 (Aggregation)

```
所有独立报告完成后,执行以下聚合计算:

1. 统计聚合
   ├── 总体平均分 = Σ(各份分数) / N
   ├── 各等级数量分布(🔴/🟠/🟡/🔵/⚪)
   ├── 各维度的平均得分(D1-D6)
   └── 各类型的平均风险分布

2. 风险聚类(Risk Clustering)
   ├── 同一风险规则在多份合同中被触发 → 归为一类
   ├── 计算每类问题的出现频率和覆盖率
   ├── 识别系统性问题(出现率>50%的共性问题)
   └── 输出"TOP 10共性问题榜单"

3. 对比分析(如有时序数据)
   ├── vs 上次审计(如有历史数据)
   ├── 各部门/各供应商之间的横向比较
   ├── 新出现的风险(上次没有的)
   └── 已修复的风险(上次有本次没有的)

4. 优先级排序
   ├── 按影响范围排序(影响合同数最多的排第一)
   ├── 按严重程度加权(致命×5 + 高危×3 + 中等×1)
   ├── 产出"整改优先矩阵"
   └── 给出"投入产出比最高"的前5项整改建议
```

## 四、效率优化策略

### 速度优化

| 场景 | 优化手段 | 预期提速 |
|:-----|:---------|:-------:|
| 同类型大批量 | 共享类型识别结果,只做差异部分 | ×2 |
| 同一供应商系列合同 | 复用当事人信息,仅检查变化条款 | ×3 |
| 历史审计过的合同 | 只做增量扫描(新条款/变更部分) | ×5 |
| 仅做快速筛查 | 跳过LOW/INFO级别,只报CRITICAL+HIGH | ×2 |
| 100份以上超大批量 | 分批处理,先出TOP风险概览再逐步深入 | 不降低但体验更好 |

### 质量保障

```
批量模式下的质量控制检查点:

☑️ 预检阶段 → 过滤掉无法处理的文件,避免垃圾进垃圾出
☑️ 抽样复检 → 从每10份中随机抽1份做深度复核
☑️ 一致性校验 → 同类合同的审查标准和尺度保持一致
☑️ 异常标记 → 评分偏离均值超过2σ的合同自动标记人工复核
☑️ 汇总交叉验证 → 聚合数据与个体数据的一致性检验
```

## 五、常见批量场景模板

### 场景A: 年度合同体检
```
输入: 企业全年签署的所有合同(或抽样)
目的: 评估整体合同风险管理水平
重点: 共性问题识别、趋势分析、制度建设建议
输出: 年度合同健康报告 + 改进路线图
频率: 建议1次/年
```

### 场景B: 供应商合同审计
```
输入: 某一供应商的全部往来合同
目的: 评估该供应商合作风险、议价筹码
重点: 价格一致性、条款变化趋势、续约风险
输出: 供应商风险档案 + 续约/更换建议
触发: 续约前3个月 / 合作中出现纠纷时
```

### 场景C: 尽职调查合同包审查
```
_input: 目标公司的核心合同(前20大客户/供应商/关联交易)
目的: M&A/DD中的合同风险评估
重点: 重大不利变更(MAC)条款、控制权变更、同意转让限制
输出: DD合同风险摘要 + 交易文件SPA披露要求
触发: 投资/并购项目启动时
```

### 场景D: 制度建设基准审计
```
_input: 公司现行所有合同模板 + 近期已签合同样本
目的: 检验模板有效性、执行偏差度
重点: 模板vs实际签订版本的偏差分析
输出: 模板修订建议 + 审批流程优化方案
触发: 公司制度建设/年度内审时
```
