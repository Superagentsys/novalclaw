# UI design provenance

The refreshed OmniNova desktop interface is an original implementation built
from neutral product requirements: semantic color tokens, accessible contrast,
responsive workspace layout, local task status, and a consistent icon system.

The `terra-faction-ui` project was consulted only as a design-analysis method.
No source code, palette values, names, logos, screenshots, artwork, fonts,
faction identities, or other protected visual assets from that repository are
included in this application. Its repository currently describes itself as a
non-commercial interface-language study and does not expose a root license, so
direct reuse is intentionally excluded.

The product themes in this implementation are original and neutrally named:

- Daylight (`daylight`)
- Midnight (`midnight`)
- Aurora (`aurora`)
- Paper (`paper`)
- Graphite (`graphite`)

Interface glyphs come from Ant Design Icons under the MIT License. See
`src-tauri/resources/THIRD_PARTY_NOTICES.md` for the retained notice, which is
included in packaged desktop builds.
