# OmniNova 桌面端界面变更记录

本文件用于记录 `zxy` 分支每次前端界面修改。后续新增页面、调整布局、修改主题或改变交互时，应在提交前补充一条记录，便于测试、验收与回退。

## 2026-08-12：深色主题可读性与技能市场修复

### 修改页面

- 模型服务：模型卡片、字段标签、下拉框、启用状态和移除按钮改用主题语义颜色，修复跟随系统暗色、深海夜航、石墨工坊中的浅灰背景撞色。
- Agents：Workspace、MBTI 人格构建、输入框与说明文字统一使用高对比主题变量。
- 渠道连接：Gateway 公网模式、运行状态网格、回调地址、警告和错误提示改用语义状态颜色。
- 任务中心：模型选择菜单明确区分浅色与深色原生控件方案，并补齐选项背景、文字和选中态颜色，修复深色主题下展开菜单的浅底浅字问题。
- 技能市场：将“全部技能”和精选推荐从已结束的大赛接口迁移到 SkillHub 正式技能库接口，支持服务端分页、分类和关键词查询，并为远端空列表增加重新加载提示。

### 新增页面

- 无。本次仅修复现有任务中心、模型服务、Agents、渠道连接和技能市场。

### 验证

- `npm run build`：通过，TypeScript 与 Vite 生产构建无错误。
- `npm run lint`：0 个错误；保留上游 `Setup.tsx` 中 1 条既有 Hooks 依赖警告，本轮未新增 lint 问题。
- 1080×720 本地视觉检查：Agents 和 Gateway 红框区域的计算颜色已切换为高对比语义色，浏览器控制台无前端错误。

## 2026-08-11：任务检查器、技能标志与暗色主题修正

### 修改页面

- 任务中心：删除会话时增加“保留任务记录”“一并删除”“取消”三种选择，删除会话后仍可查看已保留的过程和成果。
- 任务检查器：将模型阶段、工具调用、授权、文件变更和完成状态保存为本机过程摘要，任务结束后仍能查看；不记录模型流式正文、命令原始输出或敏感信息。
- 任务检查器：成果与文件变更区域增加文件类型标识、图片缩略图、文本预览、打开文件和在资源管理器中定位入口。
- 技能市场：恢复 SkillHub 接口提供的原始 Logo；远端 Logo 缺失或加载失败时，使用原有分类标志兜底；本地技能恢复原有类别标志。
- 外观主题：补齐设置页三级标题、禁用输入框和占位文字的语义颜色，提高暗色主题对比度。
- 外观主题：“跟随系统”的暗色配色改为中性灰蓝，“深海夜航”继续使用深蓝海洋配色，两者不再相同。
- 设置页：保存与网关操作区改回文档流布局，避免在低高度窗口中悬浮遮挡技能卡和配置内容。

### 新增页面

- 无。本次只完善现有任务中心、任务检查器、技能市场和外观主题，未增加导航层级。

### 数据与安全说明

- 任务过程和文件索引保存在现有的本机任务历史中，最多保留 100 个任务，每个任务最多保留 120 条过程摘要。
- 文件预览只解析任务记录的 Workspace 内文件，图片生成受限尺寸的缩略图，文本预览限制读取长度，其他格式交给系统默认应用打开。
- SkillHub Logo 只接受 `http` 或 `https` 地址，加载失败不会影响技能安装和使用。

### 验证

- `npm run build`：通过。
- `npm run lint` 及本轮目标文件 ESLint：通过。
- 本地浏览器视觉检查：澄明白昼、深海夜航、石墨工坊、技能页、任务检查器和删除弹窗均完成检查，页面控制台无错误。
- Rust `cargo check -p omninova-tauri`：通过；缺失依赖已通过 rsproxy sparse 镜像补齐。编译输出仍含项目原有的未使用代码与命名风格警告，本轮新增后端无编译错误。
