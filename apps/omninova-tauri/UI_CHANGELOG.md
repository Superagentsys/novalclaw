# OmniNova 桌面端界面变更记录

本文件用于记录 `zxy` 分支每次前端界面修改。后续新增页面、调整布局、修改主题或改变交互时，应在提交前补充一条记录，便于测试、验收与回退。

## 2026-08-20：文件操作、知识库交互与主题兼容

### 成果文件

- 文件变更类型统一显示为“新建、修改、删除”，成果列表支持右键预览、打开、定位、另存为、复制路径和重新加入对话。
- 成果预览区补充“另存为、复制路径、加入对话”入口；另存操作由桌面端安全解析 Workspace 内文件后复制到用户选择的位置。

### 知识库

- 知识库改为文档列表和正文预览分别滚动，分类栏可横向滚动，长摘要自动截断，窄窗口继续使用单列布局。
- 检索增加进行中、命中数量和无结果反馈，切换分类时清理旧结果，避免误认为旧结果属于新分类。
- 编辑内容发生变化后，取消、点击遮罩或退出应用前会提示未保存修改，防止误操作丢失正文。

### 复制与主题

- 对话消息、错误信息、代码块、网关地址、Webhook 地址和配置 JSON 统一使用带旧版 WebView 回退的剪贴板工具，并显示成功或失败反馈。
- 任务差异面板、聊天错误态、文件预览、模型下拉框与原生深色选项改用主题语义色，修复深海夜航、石墨工坊和跟随系统暗色下的固定浅色背景与低对比度文字。

### 验证

- `npm run build`：通过。
- 本次核心前端文件 ESLint：通过。
- `cargo check -p omninova-tauri`：通过；输出仅包含仓库既有警告。

## 2026-08-20：首批 P0 稳定性修复

### 知识库正文恢复

- 修复旧知识索引只有列表摘要和检索片段、缺少标准正文文件时，预览区与编辑框静默显示为空的问题。
- 正文文件缺失时优先兼容旧版标题文件，再从已保存的检索片段恢复内容，并自动补写标准正文文件。
- 前端增加原文加载和失败状态，正文读取异常时禁止进入空白编辑状态，避免误保存后覆盖原内容。

### 任务运行

- OpenAI 兼容模型的流式读取增加连接超时与 60 秒空闲保护；模型已经返回正文但连接未正常结束时，保留已收到的完整文字，避免简单问答持续转圈数分钟。
- Tauri 终态事件仍是主要完成信号，同时增加命令返回结果兜底；终态事件偶发丢失时，任务会在短暂等待后正确完成或失败，不再永久停留在“执行中”。

### 页面状态

- 自动化和知识库首次打开后保持挂载，切回任务中心再返回时保留页面内请求、筛选、滚动和编辑状态。
- 聊天页隐藏时暂停输入框与消息区尺寸测量，重新显示后再恢复监听，避免隐藏容器的零尺寸污染输入框高度和滚动位置。

### 文件与桌面体验

- 回复中的行内文件名和本地 Markdown 文件链接支持点击打开，并继续通过 Workspace 安全路径解析，不在浏览器中直接暴露任意本地路径。
- 任务检查器刷新文件清单时保留用户当前选中的成果；仅当文件已不存在时才回到第一项。
- Shell、Git、内容搜索、浏览器工具及调试命令统一使用 Windows 后台进程标记，减少执行任务时闪出黑色命令行窗口。

### 验证

- `npm run build`：通过。
- 本次修改的前端文件 ESLint：通过；全量 ESLint 仍有 `ChannelConfigForm.tsx` 的上游既有错误。
- `cargo check -p omninova-core` 与 `cargo check -p omninova-tauri`：通过；仅保留仓库既有警告。

## 2026-08-14：附件工作区挂载、成果索引与任务输入区改版

### 修改页面
