# 发票样例说明

本目录未内置真实发票图片（涉及隐私与验真合规）。

## 演示前请自备

- 一张**清晰**的增值税发票截图或照片
- 建议命名：`发票样例.jpg` 或 `发票样例.png`
- 放置于本目录 `attachments/` 下

## 要求

- 票面文字可读（代码、号码、金额、购销方税号可见）
- 若为测试票，请自行确保不含真实敏感信息
- 演示时使用支持**视觉**的大模型（GPT-4o、Qwen-VL、Gemini 等）

## 无发票时的备选

在对话中粘贴以下**虚构**票面文字，跳过 OCR，仅演示格式校验逻辑：

```
发票号码：12345678
开票日期：2026-08-15
销售方：XX矿业有限公司
销售方税号：91310000MA1XXXXXX
购买方：奥密智能贸易有限公司
购买方税号：91310000MA2YYYYYY
货物名称：铜精矿
金额：1592920.35
税额：207079.65
价税合计：1800000.00
```

然后发送 `prompts/04-单据识别.md` 中的提示词（去掉「识别图片」改为「校验以下票面数据」）。
