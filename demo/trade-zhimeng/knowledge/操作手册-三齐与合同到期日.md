# 智獴操作手册 — 三齐操作 & 合同到期日修改

> 适用岗位：业务执行岗  
> 系统：贸易智獴 V3.x  
> 最后更新：2026-07-01

---

## 一、什么是「三齐」

「三齐」指单笔贸易业务在智獴系统中达到以下三项一致：

1. **合同齐**：合同已审批通过并归档  
2. **发票齐**：进项/销项发票已核验并入台账  
3. **货权齐**：入库单/提单/仓单与合同数量、规格匹配

三齐完成后，业务方可发起**结算申请**或**放货指令**。

---

## 二、三齐操作 — 分步指引

### 步骤 1：进入业务单

1. 登录智獴 → 左侧菜单 **贸易管理** → **业务执行** → **我的业务单**  
2. 搜索业务单号或合作方名称，点击目标业务单进入详情页  
3. 在详情页顶部查看 **三齐状态灯**：红（未齐）/ 黄（部分齐）/ 绿（已齐）

### 步骤 2：核对合同齐

1. 点击 **合同信息** 页签  
2. 确认状态为 **「已审批」** 且已上传盖章扫描件  
3. 若未审批：点击 **发起合同审批**，选择合同模板并提交风控岗  
4. 合同齐条件满足后，「合同齐」指示灯变绿

### 步骤 3：核对发票齐

1. 点击 **发票台账** 页签  
2. 点击 **上传发票** → 选择进项或销项 → 上传 PDF 或图片  
3. 系统自动 OCR 提取字段；人工核对后点击 **确认入账**  
4. 若系统提示验真待对接：联系财务岗在 **发票管理 → 待验真** 队列处理  
5. 发票金额与合同金额匹配后，「发票齐」指示灯变绿

### 步骤 4：核对货权齐

1. 点击 **物流货权** 页签  
2. 上传 **入库单** 或 **提单**（支持 PDF/图片，系统 OCR 自动录入）  
3. 核对数量、规格与合同是否一致；如有溢短装，在 **溢短装说明** 中填写  
4. 货权单据审核通过后，「货权齐」指示灯变绿

### 步骤 5：完成三齐确认

1. 三项均为绿色后，点击右上角 **三齐确认** 按钮  
2. 系统弹出核对清单，确认无误后点击 **提交**  
3. 三齐状态变更为 **「已三齐」**，可发起后续结算/放货流程  

### 常见问题

| 问题 | 处理 |
|---|---|
| 合同齐灰灯 | 合同未审批或未上传盖章件 |
| 发票金额与合同不符 | 在发票台账修改或发起金额变更审批 |
| 货权数量溢短装超限 | 需风控岗审批溢短装说明 |
| 三齐按钮灰色不可点 | 任一项未齐或当前用户无权限 |

## 三、如何修改合同到期日

### 适用场景

- 合同展期  
- 审批通过后、盖章前修正有效期  
- 已盖章合同需变更（走补充协议）

### 情况 A：合同未审批 / 审批中

1. **贸易管理** → **合同管理** → 找到目标合同  
2. 状态为 **草稿** 或 **审批中** 时，点击 **编辑**  
3. 在 **基本信息** 区域找到 **合同有效期止** 字段  
4. 修改日期 → **保存** → 若已在审批流中，需 **撤回后重新提交**  

### 情况 B：合同已审批未盖章

1. 进入合同详情 → 点击 **变更申请**  
2. 变更类型选择 **「有效期调整」**  
3. 填写新到期日及变更原因 → 提交风控岗审批  
4. 审批通过后，系统更新到期日，原版本保留在 **版本历史**

### 情况 C：合同已盖章（已生效）

1. **不可直接修改** 主合同到期日  
2. 点击 **补充协议** → 新建补充协议  
3. 补充协议类型选 **「展期协议」**，填写新到期日  
4. 补充协议走完整审批 + 双章流程  
5. 主合同详情页 **关联协议** 中可查看展期记录  

### 权限说明

| 操作 | 业务执行岗 | 风控岗 | 管理员 |
|---|---|---|---|
| 编辑草稿合同到期日 | ✅ | ✅ | ✅ |
| 发起变更申请 | ✅ | ✅ | ✅ |
| 审批变更 | ❌ | ✅ | ✅ |
| 已盖章主合同直接改期 | ❌ | ❌ | ❌ |

## 四、如何修改业务方案模板

1. **系统管理** → **模板管理** → **业务方案模板**（需管理员或模板维护岗权限）  
2. 选择品类模板 → **编辑** → 修改字段或默认条款  
3. **保存** 后新版本仅对新方案生效；已有方案不受影响  
4. 业务执行岗若无权限，需提交 **IT/管理员** 工单申请修改

## 五、快捷键与入口汇总

| 功能 | 菜单路径 |
|---|---|
| 三齐确认 | 贸易管理 → 业务执行 → 业务单详情 → 三齐确认 |
| 改合同到期日 | 贸易管理 → 合同管理 → 编辑/变更申请/补充协议 |
| 改方案模板 | 系统管理 → 模板管理 → 业务方案模板 |
| 上传报关单 | 贸易管理 → 单证管理 → 报关单 → 上传（已支持 OCR 自动录入） |
