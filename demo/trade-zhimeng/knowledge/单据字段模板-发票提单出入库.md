# 单据字段模板 — 发票 / 提单 / 出入库单

> 用途：OCR 抽取后的字段映射与格式校验规则  
> 智獴路径：贸易管理 → 单证管理 / 发票台账 / 物流货权

---

## 一、增值税发票（进项/销项）

### 1.1 台账字段映射

| 字段名 | JSON 键 | 必填 | 格式规则 |
|---|---|---|---|
| 发票代码 | invoice_code | 否（全电票无） | 10 或 12 位数字 |
| 发票号码 | invoice_number | 是 | 8 或 20 位数字 |
| 开票日期 | issue_date | 是 | YYYY-MM-DD |
| 销售方名称 | seller_name | 是 | 与合同/合作方一致 |
| 销售方税号 | seller_tax_id | 是 | 18 位统一社会信用代码 |
| 购买方名称 | buyer_name | 是 | 本公司全称 |
| 购买方税号 | buyer_tax_id | 是 | 18 位 |
| 货物名称 | goods_name | 是 | 与合同品类一致 |
| 规格型号 | specification | 否 | |
| 单位 | unit | 否 | 吨/千克等 |
| 数量 | quantity | 否 | 数值 |
| 金额（不含税） | amount_excl_tax | 是 | 数值，2 位小数 |
| 税额 | tax_amount | 是 | 数值，2 位小数 |
| 价税合计 | total_amount | 是 | = amount_excl_tax + tax_amount |
| 税率 | tax_rate | 否 | 如 13%、9%、6% |

### 1.2 格式校验规则

1. `total_amount` = `amount_excl_tax` + `tax_amount`（允许 ±0.01 四舍五入误差）  
2. 税号长度 = 18 位（全大写字母+数字）  
3. 开票日期不得晚于当前日期  
4. 货物名称与业务单合同品类模糊匹配（如「铜精矿」≈「铜矿砂及其精矿」）  

### 1.3 验真状态（演示环境）

```json
{
  "verification_status": "pending_official_check",
  "verification_note": "待对接税务查验接口，AI 仅完成字段抽取与格式校验"
}
```

## 二、海运提单（B/L）

### 2.1 字段映射

| 字段名 | JSON 键 | 必填 |
|---|---|---|
| 提单号 | bl_number | 是 |
| 船名 | vessel_name | 是 |
| 航次 | voyage_no | 否 |
| 装港 | port_of_loading | 是 |
| 卸港 | port_of_discharge | 是 |
| 托运人 | shipper | 是 |
| 收货人 | consignee | 是 |
| 货描 | cargo_description | 是 |
| 件数 | packages | 否 |
| 毛重（吨） | gross_weight | 是 |
| 签发日期 | issue_date | 是 |

### 2.2 与业务单核对

- 卸港与合同交货地点一致  
- 货描/重量与合同数量在溢短装范围内（通常 ±5%）

## 六、参考：报关单（已上线能力）

海关报关单上传后，智獴已实现 OCR 自动录入以下字段：

- 报关单号、申报日期、进出口岸  
- 商品编码（HS）、商品名称、数量、金额  
- 收发货人、监管方式
