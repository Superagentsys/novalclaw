# 场景 2：业务方案自动生成

> 预计耗时：5 分钟  
> 附件：无  
> 依赖知识库：方案模板、历史同类业务、合作方信用

---

## 提示词（完整复制）

```
请先检索知识库中的「方案模板-大宗商品贸易」「历史同类业务-铜精矿」「合作方信用-摘要」。

按标准业务方案模板格式生成一版完整方案，不要自由发挥文档结构。

输入参数：
- 品类：铜精矿，Cu≥25%
- 交易规模：2.4 万吨，约 1.8 亿元
- 合作方：XX矿业有限公司
- 交割方式：上海港仓单交割
- 风控管控：预付不超过 30%，需履约担保

请输出以下五部分：
1. 完整业务方案正文（按模板章节）
2. 高风险点清单（条款、定价、账期、对手信用），标注风险等级
3. 缓释建议（付款周期、担保、保证金等），需具体可执行
4. 与历史同类业务 FA-2025-1187 / FA-2025-0923 的对比说明
5. 同步智獴审批流：输出一段 JSON（含 scheme_id、partner、amount、risk_level、submit_to），并注明「演示环境未真实提交」
```

---

## 预期输出要点

| 部分 | 应包含 |
|---|---|
| 方案正文 | 七段式模板结构（基本信息→交易要素→风控→审批） |
| 高风险 | 授信占用率 64%、本单将占满可用额度；预付 30% 边界 |
| 缓释建议 | 履约保函、卸港 SGS 检验后付款、临时增额 |
| 历史对比 | 引用 FA-2025-0923 预付 40% 导致延期教训 |
| 审批 JSON | 结构化字段 + `demo_only_not_submitted` 标记 |

---

## 现场说明

- **不要**点击「提交审批」——智獴接口未对接，只展示 JSON 结构。
- **口播**：「方案生成 + 风险识别已就绪；进审批流只需贵司开放 POST 接口。」
- 若模型未检索知识库：提醒「请先 knowledge_search」，或检查知识库是否已导入。
