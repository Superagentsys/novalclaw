> 预计耗时：4 分钟  
> 附件：无  
> 依赖知识库：`操作手册-三齐与合同到期日.md`

---

## 提示词 A — 三齐操作（必演示）

```
请先检索知识库（优先 trade-zhimeng 分类）。问题：如何完成三齐操作？按智獴系统菜单分步骤说明，包括每一步在哪个页签、需要满足什么条件、常见报错如何处理。不要泛泛而谈。
```

**预期输出要点：**
- 引用手册中的菜单路径（贸易管理 → 业务执行 → …）
- 合同齐 / 发票齐 / 货权齐 三步
- 常见问题表格

---

## 提示词 B — 修改合同到期日

```
请先检索知识库。问题：如何修改合同到期日？请区分三种情况：未审批、已审批未盖章、已盖章，分别说明操作路径和权限限制。
```

**预期输出要点：**
- 情况 A/B/C 分述
- 已盖章合同走补充协议，不可直接改

## 提示词 C — 修改业务方案模板（可选）

```
请先检索知识库。业务执行岗没有管理员权限，如何申请修改业务方案模板？说明菜单路径和需要找谁。
```

## 现场说明

- **成功标准**：回答中出现「贸易管理」「三齐状态灯」「补充协议」等手册原文术语。
